**CodeAlpha_IrisClassification**

**Project Description**
This project classifies Iris flowers into three species (setosa, versicolor and virginica) using their measurements. It is Task 1 of my CodeAlpha Data Science internship.

**Dataset**
The Iris dataset provided by CodeAlpha (from Kaggle). It has 150 flowers and 4 features:
- Sepal length
- Sepal width
- Petal length
- Petal width

**Steps**
1. Loaded the dataset and checked for missing values.
2. Made a pairplot to see how the species are different.
3. Split the data: 80% for training and 20% for testing.
4. Trained a K-Nearest Neighbors (KNN) model.
5. Tested the model using accuracy, a classification report and a confusion matrix.

**Result**
The model reached 100% accuracy on the test data. This is common for a small and easy dataset like Iris.

**Tools Used**
Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Google Colab
